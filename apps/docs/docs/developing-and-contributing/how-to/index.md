# HydroServer Developer How-To Guides

In this section, we provide documentation for developers wanting to contribute to or extend HydroServer functionality.

* **[Setting Up a Development Environment](/developing-and-contributing/how-to/setting-up-a-development-environment)**: Learn how to set up HydroServer for local development.
* **[Using the TypeScript Client](/developing-and-contributing/how-to/using-the-typescript-client.md)**: Learn how to use the HydroServer TypeScript client for web application development.
* **[Using OIDC Scopes](/developing-and-contributing/how-to/using-oidc-scopes)**: Learn which OIDC scopes a third-party app needs to call the HydroServer APIs on a user's behalf.
* **[Migrating Apps and Scripts from v1 to v2](/user-guides/how-to/migrating-apps-and-scripts-from-v1-to-v2.md)**: Learn what to update in apps and tools built on HydroServer v1's APIs or client libraries.
